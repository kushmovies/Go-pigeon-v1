# Go Pigeon V1

Android starter project for 10–50 users.

## Included
- Go Pigeon branding
- Talk to Pigeon
- Talk by Pigeon
- Anonymous-first UI (no public name/phone display)
- Supabase integration placeholder for the next step

## Build
Open this folder in Android Studio and let Gradle sync. Then Build > Build APK(s).

Package: `com.gopigeon.v1`
Version: 1.0
